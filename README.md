# 幼儿园午睡袋管理

按孩子和班级登记午睡袋的编号、材质、过敏注意事项和存放格位；周末家长扫码领回
清洗，周一送回时老师当面核对标签、清洁状态与备用睡袋使用情况。纯 Python 标准库
实现（SQLite + http.server），零第三方依赖。

## 一条本地启动命令

```bash
./run.sh            # 等价 python3 -m app.main
```

首次启动自动建库并播种演示数据（含错拿样例），打开 <http://127.0.0.1:8000/>。
重置演示数据：删除 `data/nap.db` 后重新启动。可用环境变量 `NAP_PORT` /
`NAP_HOST` / `NAP_DB` 改端口与库路径。

## 演示账号与样例

| 入口 | 值 |
| --- | --- |
| 家长端手机号 | `13800000001`（C101 朵朵）… `13800000004`（C104 米米） |
| 有效代领码 | `D-WANG01`（C101，代领人王阿姨） |
| 已撤销代领码 | `D-OLD000`（扫码立即提示旧码失效） |

- **错拿样例**：小一班 C103 豆豆 / C104 米米 周末都已领回并登记了实物互混，
  双方家长在「消息回执」页都有拿错提醒；周一若给 C103 扫入对方编号 `N-004`，
  送回核验会直接拦下并指出 `N-004` 登记属于 C104。
- **转班样例**：C202 安安在睡袋于家长家中时转入小二班，登记挂起，周一送回
  核验通过后自动落位新班格位 `B-02`。
- **污损更换样例**：N-007 污损报废，C201 乐乐正在使用备用袋 S-01（库存页可见）。

## 业务规则落点（`app/services.py`）

- 睡袋编号全库唯一；同一睡袋任一时刻只能有一条活动分配 —— 服务层校验之外，
  由 SQLite 部分唯一索引 `idx_one_active_bag` / `idx_one_active_child` /
  `idx_slot_exclusive` 兜底。
- **老师未见实物不能标记送回**：核验必须带 `seen=True`（页面对应强制勾选）。
- 送回扫到的编号与孩子当前睡袋不符即抛 `WrongBagError`，不改动任何状态。
- 代领授权有 `valid_from/valid_until` 有效期；撤销后旧码立即失效；授权码
  使用一次即不可重复领取；家长只能撤销本人孩子的授权。
- 领回后重复扫码领回被拒；标签脱落、周一未带回、污损更换、转班交接、备用袋
  启用/归还均作为不可变事件写入物品链（`bag_events`）。
- 家长端按手机号取数，只返回本人孩子的睡袋状态与本人授权。

## 页面设计

- 班级页以**儿童代号 + 格位号**定位（不使用儿童照片/真名作展示主体）。
- 领回（蓝色 ⬇「扫码领回」）与送回（绿色 ↩「核对实物后送回」）使用不同图标、
  文字与颜色；送回区强制「我已当面见到实物并核对」勾选。
- 配色为温和米底 + 墨绿主色，操作区对比度充足；无卡通装饰占据操作区。

## 组件

| 文件 | 职责 |
| --- | --- |
| `app/schema.sql` | SQLite 结构：班级/格位/儿童/睡袋/活动分配/物品链/授权/备用袋/转班/照片/消息/提醒 |
| `app/services.py` | 全部业务规则与状态流转 |
| `app/web.py` | 标准库 HTTP 服务：教师班级页、物品链、库存、消息回执、家长端 |
| `app/messages.py` | 家长消息模拟适配器（写库返回回执，不外发） |
| `app/reminders.py` | 进程内后台线程轮询 `reminders` 表，到期经适配器发消息 |
| `app/photos.py` | 标签照片本地存储（文件在 `data/photos/`，库存路径） |
| `app/seed.py` | 演示数据（含错拿、转班挂起、污损更换、撤销授权样例） |

## 测试

```bash
python3 -m unittest tests.test_services -v
```

覆盖题目点名的四项：**编号唯一、授权撤销、转班交接、重复领取**；另有未见实物
拦截、错拿拦截且归属不变、家长越权撤销、格位互斥、备用袋库存流转、标签照片
本地保存、进程内提醒到期触发与幂等、家长端数据隔离等共 20 例。
