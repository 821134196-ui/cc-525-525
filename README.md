# 幼儿园午睡袋管理

按孩子和班级登记午睡袋的编号、材质、过敏注意事项和存放格；支持周末扫码领回清洗、
下周送回时老师核对标签、清洁状态和备用睡袋使用情况。纯 Python 标准库实现，
数据存 SQLite，标签照片存本地，提醒由进程内任务处理，家长消息由模拟适配器返回。

## 启动（一条命令，含错拿样例）

```bash
python3 run.py            # 首次自动建库并播种；再次启动幂等，不重复造数据
python3 run.py --reset    # 删除 data/ 下旧库，重新播种演示数据
python3 run.py --port 8000
```

启动后控制台打印老师端、家长端（每个孩子一个专属令牌链接）和演示代领授权码。

演示数据里内置一条**错拿样例**：`B-1002`（LILY）周末领回后被 TOM 家错拿，
在「特殊事项」页可见待处理记录，点「实物换回并核对」关闭。

## 页面

| 页面 | 说明 |
| --- | --- |
| `/classes`、`/class?id=` | 班级格位板，以**儿童代号 + 格位号**定位；显示编号、材质、过敏、状态 |
| `/guardian?token=` | 家长端，凭令牌**只看本人**孩子的睡袋、物品链与代领授权 |
| `/incidents` | 代领、标签脱落、错拿、周一未带回、污损更换、转班的单独记录 |
| `/spares` | 备用袋库存 |
| `/bag?no=` | 单个睡袋的完整物品链（事件只追加、不修改）与标签照片 |

- **领回**使用下载图标 + 「领回清洗」按钮（陶土色）；**送回**使用盾牌勾选图标 +
  「见实归位」，老师必须勾选「已当面见到实物并核对标签编号」才能提交。
- 配色为温和米/青色调，正文与交互色保持足够对比度；操作区只有功能控件，无卡通装饰。

## 业务规则

- 睡袋编号全局唯一（DB UNIQUE 约束）；同一睡袋不能同时分配给两个孩子
  （`children.current_bag_id` 部分唯一索引 + 事务保证）。
- 老师**未见实物不能标记送回**：家长端只能登记「已送交、待核验」。
- 代领授权码有有效期；家长撤销后旧码**立即失效**，且授权码与孩子绑定。
- 重复领取（状态已是「已领回家」）被拦截。
- 转班要求实物在校、标签完好、非备用袋；一次事务完成旧格释放、新格占用、
  班级变更和物品链 `transfer` 记录。
- 污损袋退役 → 启用备用袋（离开库存）→ 新袋登记后备用袋自动回库。
- 周一未带回单独记录并经模拟适配器发提醒；进程内任务每小时扫描超时未送回，带冷却去重。

## 代码结构

```
napbags/
  db.py         SQLite 模式与约束
  service.py    业务服务（事务、物品链、授权、库存、错拿、转班、提醒扫描）
  web.py        http.server 页面与表单
  photos.py     纯标准库(zlib/struct) 生成标签照片 PNG
  messages.py   模拟家长消息适配器（返回送达回执）
  reminders.py  进程内守护线程提醒
run.py          一键启动 + 播种（含错拿样例）
tests/          unittest 系统测试
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：编号唯一（含备用袋/替换袋）、授权撤销即刻失效/过期/绑定孩子、
转班交接与三种拦截、重复领取、未见实物不得送回、错拿生命周期、
备用袋库存单占、家长端隔离、提醒冷却、标签照片 PNG、HTTP 端到端流程
及领回/送回图标与文字差异。
